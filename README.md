## ✨ 핵심 기능

### 1. 🗺️ 6개 스테이지 & 36마리 포켓몬 포획
- **1단계 (초원)**: (소수 한 자리 수) ÷ (자연수) 기초 (구구, 꼬렛, 캐터피 등)
- **2단계 (숲속)**: 나누어떨어지지 않아 0을 내리는 나눗셈 (피카츄, 이상해씨 등)
- **3단계 (동굴)**: (소수 두 자리 수) ÷ (자연수) (주뱃, 디그다 등)
- **4단계 (해변)**: 몫의 자연수 자리에 0이 오는 경우 (`0.xx`) (잉어킹, 꼬부기 등)
- **5단계 (화산)**: 몫이 나누어떨어지지 않아 소수 셋째 자리까지 구하는 심화 (파이리, 가디 등)
- **6단계 (체육관)**: 실생활 응용 문장제 문제 (괴력몬, 팬텀, 잠만보, 망나뇽 등)

### 2. 📝 전자칠판/학생용 계산 모달 메모장
- 'N' 키 또는 `[📝 계산 메모장]` 버튼을 누르면 화면 중앙에 즉시 모눈종이 필기 칠판이 열립니다.
- 마우스, 터치펜, 손가락으로 세로셈 계산 과정을 자유롭게 필기할 수 있습니다.

### 3. 🎲 볼 등급별 포획 확률 시스템
- **몬스터볼**: 기본 포획률 65% (간혹 튀어나와 재도전 유도)
- **수퍼볼**: 높은 포획률 85%
- **하이퍼볼**: 최고 포획률 98%
- 포켓몬이 볼을 차고 나올 때 긴장감 넘치는 애니메이션 및 즉각 재도전 기회 제공

### 4. ⚔️ 실시간 학급 협동 「전설의 레이드 보스 토벌전」
- **뮤츠 (HP 6,000)** & **레쿠쟈 (HP 12,000)**
- 교실 전자칠판에 거대한 보스와 타이머(180초), 실시간 누적 대미지/HP 게이지가 표시됩니다.
- 교실 학생 수(10~30명)를 설정하면 보스 체력과 난이도가 자동 보정됩니다.
- 학생들이 각자의 기기에서 문제를 풀 때마다 전자칠판의 보스에게 강력한 레이저 빔 타격이 가해집니다.

### 5. 🧬 스타팅 포켓몬 진화(Evolution) 시스템
- 이상해씨 ➡️ 이상해풀 ➡️ 이상해꽃
- 파이리 ➡️ 리자드 ➡️ 리자몽
- 꼬부기 ➡️ 어니부기 ➡️ 거북왕
- 피카츄 ➡️ 라이츄
- 이브이 ➡️ 부스터 / 샤미드 / 쥬피썬더
- 각 진화 단계마다 특별 보너스 수학 퀴즈를 풀어 진화 성공 컷신과 도감 수집의 성취감을 선사합니다.

### 6. 📡 무서버 P2P 실시간 멀티플레이 (PeerJS WebRTC)
- 별도의 유료 서버나 로그인 없이 브라우저 간 직접 통신으로 작동합니다.
- 교사용 화면에서 `[📡 실시간 학생 참여]`를 누르면 QR 코드가 자동 생성됩니다.
- 학생들은 스마트폰 카메라나 태블릿으로 QR 코드를 찍기만 하면 컨트롤러 화면으로 즉시 연결됩니다.

## 🚀 교실 수업 진행 가이드

1. **교실 전자칠판**:
   - 브라우저(Edge, Chrome 등)에서 **[https://junho1-commits.github.io/decimal-division-pokemon/](https://junho1-commits.github.io/decimal-division-pokemon/)** 접속
   - `[📡 실시간 학생 참여]` 클릭하여 대형 QR 코드 띄우기
2. **학생 디바이스 (스마트폰 / 크롬북 / 태블릿)**:
   - 기본 카메라로 전자칠판의 QR 코드 스캔
   - 이름 입력 후 참여 (선생님 화면에 학생 닉네임이 실시간으로 등록됨)
3. **레이드 보스전 개시**:
   - 선생님이 `[⚔️ 전설의 레이드]` 모드 선택
   - 보스 선택 (뮤츠 / 레쿠쟈) 및 학생 수 설정 후 시작!
   - 3분 동안 교실 전체가 함께 힘을 모아 소수의 나눗셈 문제를 풀며 보스를 토벌합니다.
