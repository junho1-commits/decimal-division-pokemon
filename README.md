## ✨ 핵심 기능

### 1. 🗺️ 6개 스테이지 & 포켓몬 도감 52마리
- **1단계**: (소수 한 자리 수) ÷ (소수 한 자리 수)
- **2단계**: (소수 두 자리 수) ÷ (소수 두 자리 수)
- **3단계**: (소수 두 자리 수) ÷ (소수 한 자리 수)
- **4단계**: (자연수) ÷ (소수)
- **5단계**: 몫을 반올림하여 나타내기
- **6단계**: 몫과 나머지를 실생활에 맞게 해석하기
- 학생용 생각 퀴즈는 차시별 10문제씩 60문제입니다. 계산, 역산 검산, 오류 찾기, 어림, 문장제 해석을 섞고 한 바퀴 동안 같은 문제가 반복되지 않습니다.

### 2. 📝 전자칠판/학생용 계산 모달 메모장
- 'N' 키 또는 `[📝 계산 메모장]` 버튼을 누르면 화면 중앙에 즉시 모눈종이 필기 칠판이 열립니다.
- 마우스, 터치펜, 손가락으로 세로셈 계산 과정을 자유롭게 필기할 수 있습니다.
- 학생 화면에서도 포획·친구 대전·레이드 문제의 문장을 보면서 펜, 지우개, 한 획 취소를 사용할 수 있습니다. 메모는 그 기기의 현재 화면에서만 유지됩니다.

### 3. 🎲 볼 등급별 포획 확률 시스템
- **몬스터볼**: 기본 포획률 65% (간혹 튀어나와 재도전 유도)
- **수퍼볼**: 높은 포획률 85%
- **하이퍼볼**: 최고 포획률 98%
- 포켓몬이 볼을 차고 나올 때 긴장감 넘치는 애니메이션 및 즉각 재도전 기회 제공

### 4. ⚔️ 실시간 학급 협동 「전설의 레이드 보스 토벌전」
- **뮤츠 / 레쿠쟈 / 루기아 / 칠색조 / 디아루가 / 펄기아**와 각 보스의 **이로치**를 교사 화면 상단에서 선택합니다. 보스 HP는 출전 가능한 학생 수에 맞춰 조정됩니다(최소 300).
- 교실 전자칠판에 거대한 보스와 작전 타이머(60초), 실시간 누적 대미지/HP 게이지가 표시됩니다.
- 잡은 포켓몬을 출전시켜 문제당 한 번 정답 공격을 합니다. 포켓몬의 CP, 트레이너 레벨, 타입 상성에 따라 피해량이 달라집니다.
- 체력을 1/3씩 깎으면 다음 문제로 넘어갑니다. 출전 학생 전원이 정답이면 협동 보너스로 다음 단계에 진입합니다. 원리·계산·실생활 문제를 하나씩, 총 3문제 진행합니다.
- 정답 공격이 보스에게 맞으면 교사·학생 화면에 피격 효과가 나타납니다. 이로치 레이드를 이기고 포획하면 학생 도감에 해당 외형이 저장됩니다.
- 칠판의 정답 학생 수 조절기는 교사가 수동 합동 공격을 할 때 사용합니다.
- 학생들이 각자의 기기에서 문제를 풀 때마다 전자칠판의 보스에게 강력한 레이저 빔 타격이 가해집니다.

### 5. 🧬 스타팅 포켓몬 진화(Evolution) 시스템
- 이상해씨 ➡️ 이상해풀 ➡️ 이상해꽃
- 파이리 ➡️ 리자드 ➡️ 리자몽
- 꼬부기 ➡️ 어니부기 ➡️ 거북왕
- 피카츄 ➡️ 라이츄
- 이브이 ➡️ 부스터 / 샤미드 / 쥬피썬더
- 각 진화 단계마다 특별 보너스 수학 퀴즈를 풀어 진화 성공 컷신과 도감 수집의 성취감을 선사합니다.

### 6. 📡 실시간 멀티플레이 (MQTT over WSS)
- 외부 MQTT 서버를 통해 교사와 학생이 메시지를 주고받습니다. 인터넷 연결이 필요합니다.
- 방마다 생성되는 QR에 방 코드와 통신 서버가 함께 포함됩니다. 교사 화면을 새로고침하면 새 QR로 다시 참여하세요.
- 학생 화면은 교사가 참가를 확인한 뒤에만 연결 완료로 표시합니다. 끊긴 연결은 같은 서버로 재시도하며 5초마다 현재 상태를 확인합니다.
- 교사용 화면에서 `[📡 실시간 학생 참여]`를 누르면 QR 코드가 자동 생성됩니다.
- 학생들은 스마트폰 카메라나 태블릿으로 QR 코드를 찍기만 하면 컨트롤러 화면으로 즉시 연결됩니다.

## 로컬 실행 및 연결 확인

1. `index.html`을 직접 여는 대신, 같은 폴더의 `교실_실시간_멀티플레이_시작.bat`을 실행합니다. Node.js를 우선 사용하며 없으면 Python 3을 사용합니다.
2. 학생 기기를 같은 교실 Wi-Fi에 연결하고 교사 화면의 QR을 스캔합니다. 로컬 실행 시 PC 방화벽과 Wi-Fi의 기기 간 접속 허용이 필요합니다.
3. 학생 화면의 **선생님 확인 완료**, 칠판의 학생 명단을 모두 확인한 후 레이드를 시작합니다.
4. 교사/학생 화면에 서버 연결 실패가 계속 표시되면 인터넷 및 학교망의 WSS 접속 허용 여부를 확인합니다. 기본 서버는 `broker.emqx.io:8084`입니다. 교사용 주소 끝에 `?broker=1`을 붙여 다시 열면 `broker.hivemq.com:8884`를 이용합니다(이미 쿼리가 있으면 `&broker=1`). 변경 후 새 QR로 전원 다시 참여합니다.

통신·QR 라이브러리는 `vendor/`에 포함되어 있으므로 GitHub에 배포하거나 폴더를 옮길 때 함께 포함하세요. 공개 사이트를 이용하면 로컬 서버 실행은 필요 없습니다.

검증: `node tests/multiplayer.cjs` — 30명 모의 참가, 교사 확인, QR 주소, 중복·지연 답안, 메시지 손실 후 재시도, 재접속, 체력·문제 복구를 확인합니다. 실제 교실 기기 30대 부하 시험을 대신하지는 않습니다.

## 닉네임별 이어하기와 내 포켓몬 레이드

- 학생 화면에서 닉네임을 입력하거나 저장된 닉네임 버튼을 선택합니다. **같은 기기·같은 브라우저·같은 사이트 주소**에서 닉네임별로 경험치, 도감, 차시별 진행 위치, 출전 포켓몬, 레이드 승리 기록을 자동 저장합니다. 브라우저 데이터를 지우거나 다른 기기로 옮기면 기록이 이어지지 않습니다.
- 기존 단일 학생 저장 기록은 당시 마지막으로 저장된 닉네임에만 처음 한 번 가져옵니다. 다른 닉네임은 새 모험으로 시작합니다.
- 교사 참여 창의 ‘이전에 참여한 닉네임’에는 참여자 명단과 최근 도감 수·경험치가 저장됩니다. 실시간 접속자 수와 구분됩니다.
- 학생의 ‘내 포켓몬’에서 잡은 포켓몬을 출전 파트너로 선택합니다. 처음에는 차시 문제를 풀어 포켓몬을 잡아야 합니다. 레이드 도중에도 포획하러 갔다가 복귀할 수 있습니다.
- 정답 공격은 포켓몬별 기술로 표시됩니다. 보스별로 유리한 타입은 1.5배 피해를 줍니다. 수업용으로 단순화한 전투 규칙입니다.
- 오답이면 출전 포켓몬이 반격으로 체력을 최대 12 잃습니다. 쓰러지면 무료 회복 또는 다른 포켓몬으로 교체할 수 있습니다. 체력은 각 레이드마다 새로 시작합니다.
- 효과음·음성·BGM은 유지하며 상단의 세 가지 소리 버튼만 제거했습니다.
- 배포에는 `classroom-adventure.js`와 `adventure.css`도 포함해야 합니다.

## 친구 대전

1. 학생 두 명이 같은 교사 방에 접속해 포켓몬을 한 마리 이상 잡습니다.
2. 각자 생각 퀴즈를 오늘 5개 맞히면 대전권 1장을 얻습니다. 학생 화면에서 상대를 골라 신청하고, 상대가 수락하면 대전이 시작됩니다.
3. 세 라운드에서 원리·계산·실생활 문제를 하나씩 풉니다. 두 선수 모두 HP 100으로 시작하고 정답마다 상대에게 35 대미지를 줍니다. 60초 안에 답하지 않으면 해당 라운드 공격은 없습니다. 오답이어도 포켓몬은 잃지 않습니다.
4. 승리 120 XP, 무승부 60 XP, 패배 40 XP입니다. 레이드가 시작되어 대전이 중단되면 대전권을 돌려줍니다. 연결이 끊겼다가 돌아오면 진행 중인 문제를 다시 받으며, 답안과 보상은 중복 처리되지 않습니다.

학생 화면 상단의 `[📝 계산 메모장]`은 친구 대전 중에도 사용할 수 있습니다. 키보드에서는 `N`으로 열고 `Esc`로 닫습니다. 화면이 낮은 전자칠판에서는 보스 영역을 스크롤해 작전 패널까지 볼 수 있습니다.

## 레벨별 포획과 중복 강화 (2026-10-01)

- 차시 번호는 유지합니다. 모든 차시에서 꼬렛·구구 같은 약한 포켓몬부터 시작합니다.
- 트레이너는 300 XP마다 레벨이 오릅니다. 일반 포켓몬은 기본 CP에 따라 Lv.1~5에서 포획할 수 있습니다. 스타팅 포켓몬·피카츄 등은 Lv.2, 이브이는 Lv.3부터 열립니다. 포획 선택 목록에 필요한 레벨과 누적 포획 수를 표시합니다.
- 서로 다른 생각 문제 2개를 맞히면 포획합니다. 정답은 30 XP, 포획은 매번 100 XP를 줍니다. 이미 잡은 포켓몬도 선택하여 다시 잡을 수 있습니다.
- 최초 포획은 파트너로 남고 이후 포획은 강화용 중복 수에 쌓입니다. 같은 포켓몬의 중복 2마리를 소모하여 강화 1회를 합니다. 누적 포획 수는 줄지 않습니다. 기존 도감과 강화 기록은 유지하며 과거 훈련 에너지는 새 강화 재료로 사용하지 않습니다.
- 정답·오답 모두 해설을 확인하고 다음 문제로 넘어갑니다. 오답으로 도감 포켓몬을 잃지 않습니다. 차시마다 확장한 문제은행을 무작위로 한 순환 동안 중복 없이 출제합니다.
- 레이드의 세 문제는 원리·계산·실생활로 구성합니다. 실생활 문장제에는 불필요한 수치가 포함되며, 해설에서 필요한 정보와 제외할 정보를 설명합니다. 연료량을 두 번 계산해 비교하는 문제도 포함합니다.

## 지도서 기반 풀이 실습

생각 퀴즈와 풀이 실습이 번갈아 나옵니다. 풀이 실습에서는 분수로·자연수로·세로셈 방법을 골라 계산 과정을 직접 채웁니다. 반올림은 표시할 자리와 판단 숫자, 남는 양은 통 수와 원래 단위의 양을 구합니다. 모든 칸이 맞아야 정답 보상이 주어집니다. 자세한 근거는 `지도서_반영_문항설계.md`를 확인하세요. 배포 파일에 `guided-practice.js`도 포함해야 합니다.

## 학생 음성 재생

학생 참여 시 브라우저의 오디오를 활성화합니다. 학생 화면에서 문제 듣기·풀이 안내 듣기·해설 듣기를 사용할 수 있습니다. 새 문제가 나오면 읽어 주며 포획·오답 안내도 학생 기기에서 재생합니다. 태블릿의 자동 재생 제한이 있을 때는 문제 듣기를 눌러 재생할 수 있습니다. 기존 Typecast Lala 목소리를 재사용하며 문제, 풀이 방법, 해설을 미리 만든 음성 파일로 제공합니다.

음성 생성은 `TYPECAST_API_KEY`를 사용자 환경 변수에 설정하고 `node scripts/generate-typecast-voices.cjs`를 실행합니다. 키는 배포 파일에 포함하지 않습니다. 이미 있는 음성은 재사용하고 중단 후 다시 실행하면 이어서 생성합니다.
